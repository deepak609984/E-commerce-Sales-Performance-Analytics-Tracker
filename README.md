# 📊 E-Commerce Sales & Performance Analytics Tracker

An interactive Excel dashboard built to analyze and track e-commerce sales performance, regional revenue, executive contributions, and product-wise insights using Advanced Excel, Power Query, and Pivot Tables.

---

## 🚀 Project Overview
This project processes raw e-commerce sales records, cleans and structures the dataset using **Power Query (ETL)**, and delivers a dynamic, executive-ready MIS dashboard. It helps management track total revenue, regional sales distribution, top-performing products, and individual sales executive targets at a glance.

---

## 🛠️ Tools & Techniques Used
- **Data Transformation:** Power Query (ETL, Data Cleaning, Formatting)
- **Data Modeling & Analysis:** Pivot Tables, Dynamic Named Ranges, Slicers
- **Advanced Formulas:** XLOOKUP, INDEX & MATCH, SUMIFS, COUNTIFS
- **Data Visualization & Reporting:** Interactive Charts, KPI Cards, MIS Reporting Layout

---

## 📈 Key Dashboard Metrics
- **Total Revenue:** ₹3,98,96,10,341
- **Total Quantity Sold:** 120,096 Units
- **Top Performing Month:** March (Highest Revenue: ₹7,10,77,436)
- **Top Region:** Vadodara (Leading regional revenue)
